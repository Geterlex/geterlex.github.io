Основы работы с Git

Освойте базовый цикл Git: создание или клонирование репозитория, проверка файлов, коммиты, просмотр истории и отмена изменений.

Материалы раздела

Как создать репозиторий Git

Создайте локальный репозиторий в существующем проекте через git init и узнайте, когда вместо этого нужен git clone.

Как клонировать репозиторий Git

Получите файлы и историю существующего проекта с помощью git clone. Проверьте папку, ветку и удалённый адрес после клонирования.

Как читать состояние репозитория в Git

Разберитесь в выводе git status: какие файлы не отслеживаются, какие изменены и какие попадут в ближайший коммит.

Добавление файлов в индекс Git

Подготовьте выбранные файлы к коммиту через git add и проверьте, какие изменения попадут в историю.

Как сделать коммит в Git

Создайте осмысленный коммит Git: проверьте индекс, сохраните подготовленные изменения и посмотрите результат в истории.

История коммитов Git

Посмотрите историю проекта через git log, найдите хеш нужного коммита и изучите изменения выбранного файла.

Отмена изменений в Git

Сравните restore, reset и revert. Выберите операцию по тому, где находятся правки: в файлах, индексе, локальном или опубликованном коммите.

Чтобы увидеть операции в одном сценарии, откройте практический пример.
