Правила использования GitStart

Как пользоваться бесплатным справочником GitStart, что сохраняет браузер и как устроена обратная связь на GitHub.

Как пользоваться материалами

Справочник открыт без регистрации. Команды можно копировать для выполнения упражнений и своей работы. В примерах с адресом репозитория подставляйте собственный адрес. При упоминании материала в работе указывайте ссылку на статью GitStart. У сторонних источников действуют их условия использования.

Что сохраняет браузер

Выбор светлой или тёмной темы сохраняется в локальном хранилище браузера. Поиск выполняется в браузере по загруженному списку статей. В этой версии сайта нет форм с персональными данными и счётчика аналитики.

Внешние сайты и обратная связь

Сайт размещён на GitHub Pages. Для обращения через GitHub Issues используется учётная запись GitHub, и сообщение может быть публичным. Условия обработки данных GitHub описаны в политике GitHub.
