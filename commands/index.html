Основные команды Git

Найдите нужную команду Git в справочнике из 15 команд: назначение, пример и ссылка на подробную инструкцию.

Справочник основных команд Git
КомандаНазначениеПример
git initСоздаёт историю Git для текущей папки.git init -b main
git cloneСоздаёт локальную копию файлов и истории.git clone URL
git statusПоказывает текущую ветку и состояние изменений.git status --short
git addДобавляет выбранные изменения в индекс.git add -- README.md
git commitСохраняет подготовленный снимок с сообщением.git commit -m "Добавить описание проекта"
git logПоказывает коммиты и их сообщения.git log --oneline -5
git branchПоказывает, создаёт и удаляет указатели веток.git branch
git switchПереключает рабочую папку на выбранную ветку.git switch main
git mergeИнтегрирует изменения указанной ветки в текущую.git merge practice/notes
git remoteПоказывает и изменяет сохранённые адреса серверов.git remote -v
git pushОтправляет коммиты на выбранный удалённый адрес.git push -u origin main
git pullЗагружает и применяет удалённые изменения.git pull --ff-only
git fetchЗагружает коммиты и обновляет ссылки на удалённые ветки.git fetch origin
git resetПеремещает указатель ветки; режим определяет изменения файлов и индекса.git reset --soft HEAD~1
git revertСоздаёт новый коммит, отменяющий выбранное изменение.git revert HEAD

Откройте страницу команды, чтобы проверить условия примера. Для последовательных упражнений используйте практический пример.
