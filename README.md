# GitStart

Статический учебный сайт о Git и GitHub. HTML, CSS и JavaScript работают без сборки и сервера приложений.

## Проверка на компьютере

Распакуйте архив и запустите `run_local.bat` в папке `GitStart`. Нужен Python 3. Откройте `http://127.0.0.1:8000/`. В терминале можно запустить `py -3 serve_local.py` (Windows) или `python3 serve_local.py` (macOS/Linux). Для другого порта добавьте `--port 8001`.

Локальный сервер показывает пользовательскую страницу ошибки с HTTP 404. Для проверки откройте `http://127.0.0.1:8000/test/missing/`. Пути к страницам и ресурсам начинаются от корня сайта, поэтому открывайте сайт через сервер.

## Публикация

1. Скопируйте **содержимое** папки `GitStart` в корень своего существующего репозитория, включая `.nojekyll` и `yandex_57fda0687f2b5e33.html`. Архив не содержит каталога `.git`.
2. Опубликуйте изменения в источнике, уже выбранном для `https://geterlex.github.io/` в настройках GitHub Pages.
3. Проверьте HTTPS, `https://geterlex.github.io/sitemap.xml` и вложенную ошибочную ссылку. После публикации передайте актуальный sitemap в Яндекс Вебмастер и при необходимости запросите переобход важных страниц.

В исходниках канонические адреса настроены для размещения в корне `https://geterlex.github.io/`. Внутренние ссылки используют адреса каталогов без `index.html`. Если хостинг обслуживает прямой URL с `index.html`, его каноническая версия указана в HTML; при включённом JavaScript адрес также приводится к чистому виду с сохранением параметров и якоря. Это не серверный редирект.

## События для будущей аналитики

Сайт не подключает Яндекс Метрику и не отправляет сведения о действиях. В JavaScript есть локальное событие `gitstart:goal`: свойство `event.detail.name` принимает `copy_command` после успешного копирования или `next_lesson` при переходе по ссылке следующего урока. После подключения собственного счётчика эти события можно связать с одноимёнными целями. Демонстрационный счётчик для GitStart не подходит. Ссылки принимают UTM-параметры без изменения canonical.

При добавлении новой статьи обновите её путь и метаданные, обе карты сайта и `assets/search-index.json`.
