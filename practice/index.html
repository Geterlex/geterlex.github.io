Практика Git на одном проекте

Создайте учебный репозиторий, запишите первый коммит, добавьте ветку и объедините изменения. Есть исходный файл и ожидаемые результаты.

Подготовка

Проверьте установку Git и имя и адрес автора. Используйте Git Bash в Windows или терминал macOS/Linux. Выполняйте шаги в новой папке. Файл README можно создать командой ниже или скачать и сохранить как README.md.

Скачать исходный README (TXT)

1 Создайте проект и добавьте файл

После создания папки и файла подготовьте README. Сокращённый статус покажет добавленный файл. Если вы скачали исходный файл, положите его в новую папку под именем README.md и пропустите строку с printf.

Команды
mkdir gitstart-practice
cd gitstart-practice
git init -b main
printf '# Мой учебный проект\n' > README.md
git add -- README.md
git status --short

Ожидаемый вывод git status --short
A  README.md

2 Запишите первый коммит и откройте ветку

Сохраните подготовленный README. В отдельной ветке допишите одну строку и сохраните её вторым коммитом.

Команды
git commit -m "Добавить описание проекта"
git switch -c practice/notes
printf '\nЗаметка из учебной ветки.\n' >> README.md
git add -- README.md
git commit -m "Добавить заметку"
git branch --show-current

Ожидаемый вывод git branch --show-current
practice/notes

3 Объедините изменения

Перейдите в main и добавьте изменения учебной ветки. Параметр --no-ff создаёт отдельный коммит слияния. В истории будут три коммита, а после них статус не должен показать незаписанных правок.

Команды
git switch main
git merge --no-ff practice/notes -m "Добавить учебную ветку"
git log --oneline --graph --decorate --all -4
git status --short

Пример результата: хеши у вас будут другими
*   a1b2c3d (HEAD -> main) Добавить учебную ветку
|\
| * e4f5a6b (practice/notes) Добавить заметку
|/
* c7d8e9f Добавить описание проекта

4 По желанию опубликуйте результат

Создайте собственный пустой репозиторий gitstart-practice на GitHub. Подставьте свой логин вместо YOUR_LOGIN и выполните команды. Если origin уже существует, сначала проверьте его адрес.

Команды
git remote add origin https://github.com/YOUR_LOGIN/gitstart-practice.git
git push -u origin main

На GitHub в ветке main должен появиться README с учебной заметкой. Шаги 1–3 работают локально без учётной записи.
