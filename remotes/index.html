Удалённые репозитории Git

Подключите удалённый репозиторий, проверьте origin и используйте fetch, pull и push для синхронизации проекта.

Материалы раздела

Что такое удалённый репозиторий Git

Узнайте, как Git хранит адреса удалённых репозиториев, что значит origin и чем отличаются fetch, pull и push.

Подключение удалённого репозитория Git

Привяжите локальный проект к удалённому репозиторию через git remote add, проверьте origin и смените адрес при необходимости.

Проверка изменений через git fetch

Загрузите информацию с удалённого репозитория без изменения текущей ветки и сравните её с origin/main.

Получение изменений через git pull

Обновите текущую ветку из удалённого репозитория и проверьте, в каких случаях git pull --ff-only останавливается.

Отправка изменений на сервер через git push

Отправьте коммиты на свой удалённый репозиторий, настройте отслеживание ветки и разберите отказ при отправке.

Чтобы увидеть операции в одном сценарии, откройте практический пример.

Разница между fetch и pull

КомандаРезультат
git fetchПолучает новые коммиты и обновляет ссылки наподобие origin/main. Текущая ветка и файлы не меняются.
git pullПолучает и интегрирует изменения. С --ff-only остановится, если истории разошлись.
