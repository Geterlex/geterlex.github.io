Проверка изменений через git fetch

Загрузите информацию с удалённого репозитория без изменения текущей ветки и сравните её с origin/main.

Загрузка без слияния

После git fetch origin обновятся ссылки на ветки сервера, например origin/main. В рабочей папке ничего не изменится. В примере удалённая ветка main должна существовать.

Команды
git fetch origin
git log --oneline HEAD..origin/main

Чем fetch отличается от pull

КомандаРезультат
git fetchПолучает новые коммиты и обновляет ссылки наподобие origin/main. Текущая ветка и файлы не меняются.
git pullПолучает и интегрирует изменения. С --ff-only остановится, если истории разошлись.
