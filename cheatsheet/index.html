Шпаргалка Git

Краткая шпаргалка по Git: команды для репозитория, коммитов, веток и сервера, а также отличия fetch от pull и reset от revert.

Репозиторий

git init

Создаёт историю Git для текущей папки.

git clone

Создаёт локальную копию файлов и истории.

git status

Показывает текущую ветку и состояние изменений.

Коммиты

git add

Добавляет выбранные изменения в индекс.

git commit

Сохраняет подготовленный снимок с сообщением.

git log

Показывает коммиты и их сообщения.

Ветки

git branch

Показывает, создаёт и удаляет указатели веток.

git switch

Переключает рабочую папку на выбранную ветку.

git merge

Интегрирует изменения указанной ветки в текущую.

Удалённые репозитории

git remote

Показывает и изменяет сохранённые адреса серверов.

git fetch

Загружает коммиты и обновляет ссылки на удалённые ветки.

git pull

Загружает и применяет удалённые изменения.

git push

Отправляет коммиты на выбранный удалённый адрес.

Fetch и pull

КомандаРезультат
git fetchПолучает новые коммиты и обновляет ссылки наподобие origin/main. Текущая ветка и файлы не меняются.
git pullПолучает и интегрирует изменения. С --ff-only остановится, если истории разошлись.

Restore, reset и revert

КомандаЧто изменится
git restoreМеняет выбранные файлы или индекс. Существующие коммиты остаются в истории.
git resetПри указании коммита перемещает ветку. Вариант --soft оставляет индекс и файлы как есть.
git revertСоздаёт новый коммит с обратными изменениями. Удобен для общей истории.

Проверьте эти команды в учебном проекте. Перед отменой убедитесь, что сохранили нужные изменения.
