Как создать репозиторий на GitHub

Создайте пустой репозиторий на GitHub, выберите видимость проекта и подключите его к существующей локальной истории.

Создание на GitHub

Войдите в GitHub и выберите создание нового репозитория. Укажите владельца, имя и видимость. Если у вас уже есть локальная история, создайте пустой репозиторий без начального README, лицензии и .gitignore.

Подключение локальной папки

Скопируйте HTTPS-адрес и вставьте его в команду ниже вместо примера. Если origin уже задан, сначала проверьте его адрес. Перед публикацией убедитесь, что в истории проекта нет секретов и личных файлов.

Команды
git remote add origin https://github.com/YOUR_LOGIN/gitstart-practice.git
git remote -v

Дальше выполните отправку проекта.
