Клонирование репозитория с GitHub

Скопируйте URL из меню Code на GitHub, выполните git clone и проверьте адрес origin в полученной копии.

Где взять ссылку

Откройте репозиторий на GitHub. В меню Code выберите HTTPS или SSH и скопируйте адрес. Для SSH предварительно настройте ключ. Если репозиторий закрытый, нужны права доступа.

Откройте полученную папку

В примере используется публичный репозиторий книги Pro Git. После клонирования откройте созданную папку и посмотрите адрес удалённого репозитория.

Команды
git clone https://github.com/progit/progit2.git
cd progit2
git remote -v
