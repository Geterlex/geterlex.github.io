Как разрешить конфликт слияния Git

Найдите конфликтующие файлы, разберите маркеры конфликта Git и продолжите или отмените начатое слияние.

Найдите конфликт

Git останавливает слияние, когда не может автоматически объединить изменения. Выполните git status и откройте конфликтующие файлы. В текстовом файле маркеры <<<<<<<, ======= и >>>>>>> отделяют версии.

Выберите итоговый текст

Оставьте нужную комбинацию, уберите маркеры и проверьте файл. Если конфликт был в README.md, отметьте его решённым и завершите слияние:

Команды
git add -- README.md
git status
git merge --continue

Если вы хотите отказаться от текущего слияния, используйте git merge --abort. Для конфликта при перебазировании команды отличаются. Важные незакоммиченные правки лучше сохранять до начала операции.

Обновлено 5 ноября 2026 г. Официальные источники: Документация git merge.
