Первоначальная настройка Git

Настройте имя и адрес автора коммитов, проверьте значения git config и узнайте разницу между настройками проекта и пользователя.

Имя и адрес автора

В каждом коммите Git сохраняет имя и электронную почту автора. Замените значения в примере на свои. Для публичных репозиториев можно взять адрес noreply из настроек GitHub, если не хотите раскрывать личную почту.

Команды
git config --global user.name "Иван Иванов"
git config --global user.email "you@example.com"

Настройки для одного проекта

Параметр --global действует для пользователя компьютера. Чтобы установить другое имя или адрес только для текущего репозитория, выполните команды в его папке с --local вместо --global.

Проверьте значения

В папке будущего проекта проверьте действующие имя и адрес. Изменение настроек не переписывает уже созданные коммиты.

Команды
git config user.name
git config user.email
